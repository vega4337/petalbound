Play the game ↗

Play on your computer

  1. Extract the entire ZIP. Keep assets, src, styles.css, and index.html together.
  2. Open index.html in a modern browser. On Windows, you can also double-click PLAY-WINDOWS.bat.
  3. Click Begin the story. Music begins after your first click. The ? button is your field guide.

If your browser blocks local files, run SERVE-WINDOWS.bat (uses Python if installed), or run python -m http.server 8000 inside the game folder and open http://localhost:8000. No build or dependency installation is needed for the game.

Put it on GitHub Pages

  1. Create a public GitHub repository, such as petalbound.
  2. Upload the extracted folder’s contents, including the full assets and src folders. index.html must sit directly in the repository root. Upload the files, not the ZIP.
  3. Commit to the main branch.
  4. Open Settings → Pages → Build and deployment. Select Deploy from a branch, then main and /(root), and save.
  5. Wait for GitHub to show the published website link. Open that link on your computer, phone, or tablet.

A few useful controls

A / D or arrows: move. Space / W / ↑: jump; hold for height. Shift: sprint or dash. P / Escape: pause. M: mute. R: restart. F: fullscreen. Touch buttons and standard gamepads are supported.

Artwork and music are already included

You do not need to find or download anything else. The four music files live in assets/audio. To use your own tracks, place them there and change the music paths in src/assets.js. The README explains the file layout and customization.

Story checkpoint gardens and preferences save in your browser. A new browser or a different website address has its own save. The story ends at the Moonkeeper; endless wandering is a separate mode.

Original AI-assisted painted art and an original rendered instrumental score. No accounts, analytics, advertising, or network dependencies.
